# 06: `explain <id> --llm --full` як NL outline з походженням

**Джерело:** spec §4.1 A2; research-c4-zoom-literature §5 (NL Outlines), §9 п. 3

**What to build:** Рівень `full` пояснення має фіксовану структуру розділів: «Призначення», «Кроки», «Гілки й крайні випадки», «Виклики» (список ID зі знімка; нерозв'язані — з позначкою ◌ і причиною, без вигаданих ребер), «Потоки й правила» (де вузол бере участь). Промпт вимагає цих заголовків; відповідь перевіряється: кожне посилання на ID існує у знімку або є `planned`, інакше пояснення не записується, код 1 з назвою ID (як для brief). Збережений файл `explain/<id>.md` починається рядком походження `модель · дата · fingerprint`; `explain <id> --full` без `--llm` показує його з позначкою `stale` за потреби. TUI `F3` рендерить розділи заголовками; офлайн без збереженого `full` — algo-зведення як зараз.
