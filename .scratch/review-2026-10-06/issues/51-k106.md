# 51: K106 не знімається правилом на перетині, якщо в нього більше однієї цілі

**Status:** ready-for-agent

**Type:** code

**Blocked by:** None (can start immediately)

**Verify:** `npm run typecheck` · `npm test` · `node bin/keylang.js map --check` · `node bin/keylang.js check`

**Джерело:** [рев'ю 2026-10-06](../../../docs/review-2026-10-06.md) §2, рівень **P3**, зона `x-rule-flow-semantics`, верифікація: confirmed.

**Місце:** `src/rules.ts:755` (рецензент указав `src/rules.ts:755`)

## Що не так

semantics.md: «Правило на перетині прибирає K106» (жодне правило не має областей рівно на перетині). Код шукає лише правило з рівно одною ціллю (`rule.b.length === 1 && rule.b[0] === tgt`). Тож `deny app.x.y domain.storefront, infra.db` перетин покриває, але K106 лишається, а підказка радить додати правило, яке вже є.

## Сценарій збою

rules: `- allow app.x.y domain`, `- deny app domain.storefront`, `- deny app.x.y domain.storefront, infra.db`. Результат: `K106 … add allow app.x.y domain.storefront or deny app.x.y domain.storefront`. Якщо прибрати `, infra.db` з третього рядка, K106 зникає.

## Як відтворити

scratchpad/review/rule-flow-semantics/f4: `node bin/keylang.js check keylang` з трьома правилами дає `keylang/rules.md:3:1: K106 … deny wins (deny-overrides); add …`. З `- deny app.x.y domain.storefront` K106 немає.

Доказ верифікатора:

> I reproduced this myself at HEAD 45cc74d. The K106 check is at src/rules.ts:755: `if (ruleset.some((rule) => rule.a === src && rule.b.length === 1 && rule.b[0] === tgt)) continue;`. A rule that covers the intersection but has more than one target never counts. The oracle in tests/rules-model.test.ts:209 has the same `b.length === 1` line, so it does not show the behaviour is intended.
> 
> The documented contract says the opposite. docs/semantics.md:211-214 reads "жодне правило не має областей рівно на перетині … Правило на перетині прибирає K106". docs/grammar.md:341 defines `allow|deny <a> <b>…` as one source and several targets, and the `score` predicate in semantics.md takes the max over those targets. So `deny A B, C` covers the pair (A, B). docs/review-2026-10-05.md has no item about this (grep for K106, incomparable and непорівнюв finds nothing), so it is not a known open item.
> 
> Repro 1, no snapshot. Fixture is in scratchpad/verify/x-rule-flow-semantics-5-0/{a,b,c,d}. map.md has app.x.y, domain.storefront and infra.db. The command was `node /home/kosmodev/pet_project/keylang/bin/keylang.js check keylang`, with HOME and XDG_* set to the scratch dir.

## Що зробити

- Замінити умову на `rule.a === src && rule.b.includes(tgt)`, щоб правило з кількома цілями, одна з яких дорівнює перетину, теж знімало K106. Так само оновити оракул у rules-model.test.ts і додати тест з `deny app.x.y domain.storefront, infra.db`.
