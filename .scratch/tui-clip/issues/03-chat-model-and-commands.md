# 03: Розмова з моделлю й команди без моделі

**Status:** ready-for-agent

**Type:** code

**Blocked by:** 02

**Verify:** `node --test tests/tui-clip-chat.test.ts` · `npm run typecheck` · `npm test` · `node bin/keylang.js map --check` · `node bin/keylang.js check --strict`

**Джерело:** spec §3, §4.3, §4.4, П3, П6; [ADR 0021](../../../docs/adr/0021-tui-clip-chat.md) п. 4, 5; [ADR 0019](../../../docs/adr/0019-tui-assistant-without-harness.md) п. 2

**What to build:** Повідомлення в чаті йде моделі з `agent` разом із контекстом відкритого файла, і відповідь з'являється в історії. Рядок, що починається з `/`, виконує детерміновану команду без моделі. Без `agent` чат пояснює, як його задати, а команди працюють.

- **Операція.** Нова операція `assistant-reply` у `src/operations/` виконується у worker, як `draft-flow`. Запит: історія розмови до 16 000 символів (старіші повідомлення відкидаються цілими); шлях і текст буфера, до 400 рядків навколо курсора; рядок курсора й ID під ним; текст пакета `F4`; стадія й прогалини фічі, коли відкрито файл фічі; відкриті питання (тікет 05, до нього список порожній). `maxTokens` — 1 500.
- **Системний промпт** (spec §4.3): коротко, мовою людини, лише про цей репозиторій; не вигадувати вердиктів і ребер; зміну специфікації давати одним блоком `keylang path=<файл>` з повним текстом; коду не писати.
- **Очікування.** Очі `◔◔`, у вікні «думаю… Esc — скасувати», запит видно в `F4`. Запит один за раз. Esc скасовує запит через `AbortSignal`, і нічого не записано.
- **Команди.** `/explain`, `/feature`, `/check`, `/questions`, `/new`, `/help` (spec §4.4) викликають наявні операції чи стан сесії. Невідома команда показує список команд.
- **Без `agent`** вільний текст дає пояснення з spec §4.3, а запитів 0.

- [ ] тести тікета — у новому файлі `tests/tui-clip-chat.test.ts`
- [ ] e2e з `mockModel`: одне повідомлення дає рівно один запит. Промпт містить текст повідомлення, шлях відкритого файла, рядок курсора, ID під ним і текст пакета `F4`. Відповідь стоїть в історії `◕◕ › …`
- [ ] e2e: друге повідомлення несе в промпті перше повідомлення й відповідь на нього. Історія понад 16 000 символів відкидає найстаріші повідомлення цілими
- [ ] e2e з моделлю, що тримає відповідь: очі `◔◔`, у вікні «думаю…». Enter під час очікування не дає другого запиту. Esc скасовує, `aborted` = 1, у історії «скасовано», дерево файлів не змінилося (`treeBytes`)
- [ ] e2e: помилка моделі показує причину в чаті, і нічого не записано
- [ ] e2e без `agent`: вільний текст дає пояснення, `/explain K105` друкує те саме, що `keylang explain K105`, `/check` — підсумок `✗ ◌ ✓` сесії. Запитів до моделі 0
- [ ] `/feature <slug>` показує стадію й прогалини тієї ж бази, що команда `feature`. `/new` очищає історію. `/nope` друкує список команд
- [ ] `state.analysis.verdicts` після відповіді той самий
- [ ] `docs/tui.md`, розділ «Скрепка»: що йде моделі, команди, поведінка без `agent`; згадка операції в абзаці про операції TUI
