# macOS: одне написання шляхів специфікації

**Джерело:** HANDOFF-2026-10-04, рядок `wip/macos-path-spelling`.

На macOS `os.tmpdir()` лежить під `/var/…`, що є лінком на `/private/var/…`. Коли репозиторій досягається через лінк над ним, CLI і TUI пишуть той самий файл по-різному (`/var/…` проти `/private/var/…`), і `check` не знаходить знімок для шляху специфікації. На Linux повний `npm test` зелений; на macOS падають 4 тести (3 через написання шляхів, 1 — `ENOTCACHED` без мережі, це середовище).

Незавершений фікс — гілка `origin/wip/macos-path-spelling` (`34924c5`): `spelledUnder` у `src/analyze.ts` зводить шлях, що досягає кореня лише через лінк над ним, до написання під `root`; виклик у `runCheck` (`src/operations.ts`); правки `tests/cli.test.ts`, `tests/tui-fixture.ts` і карти.

## Несумісні зміни

Немає: змінюється лише нормалізація абсолютних шляхів, які вже вказують у репозиторій.
