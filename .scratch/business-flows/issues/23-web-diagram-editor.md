**Джерело:** [spec](../spec.md); [рев'ю 2026-10-06](../../../docs/review-2026-10-06.md)

## What to build

Повноцінне графічне полотно, як diagrams.net, але фігури — сутності keylang.

- **Рушій:** maxGraph (`@maxgraph/core`, open-source наступник mxGraph — рушія draw.io) — дає звичну поведінку draw.io: фігури, з'єднання з точками прив'язки, перетягування, ресайз, групування/контейнери, вирівнювання й напрямні, мультивибір, zoom/pan, undo/redo, гарячі клавіші. Альтернатива для порівняння в ADR-примітці тікета — xyflow; вибір фіксується в `docs/adr/0024-diagram-editor.md` (короткий ADR у цьому тікеті).
- **Палітра:** шар (контейнер-доріжка), модуль, fn, тип, крок, шлюз `when`, `parallel`, подія, таймер, вебхук/зовнішня система, примітка (проза). Кожна фігура несе ID або `planned`.
- **З'єднання:** виклик/крок (послідовність), залежність шарів (`allow`/`deny` як стиль лінії), подія→підписник, `continues`.
- **Властивості:** панель праворуч — ID, вид, сигнатура для `planned`, тести (`test file "name"`), опис.
- **Режими:** «з коду» (фігури з моделі 20, редагуються лише розкладка й нотатки) і «чернетка» (усе редаговане).
- **Збереження:** позиції — файл розкладки (24); зміст — лише через пропозиції (24).
- Експорт PNG/SVG з полотна.
