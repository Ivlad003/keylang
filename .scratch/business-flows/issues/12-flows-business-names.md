## What to build

Технічні тригери (`POST /V1/carts/mine/payment-information`) треба перетворити на бізнес-мову («Оплата й оформлення замовлення»).

- `flows discover --mode llm|hybrid`: модель отримує точку входу, кроки, brief-и вузлів (ADR 0004) і дає: назву процесу, 2–4 речення опису, домен (Каталог, Кошик, Оформлення, Оплата, Доставка, Повернення, Інтеграції…), вхідні/вихідні сутності.
- Записується в пропозицію як опис під `# flow` з походженням `<!-- keylang:llm model=… date=… -->`; групування — в `keylang/flows/discovered/README.md` (процес → флоу).
- Stale-механізм як у поясненнях: зміна fingerprint кроків робить опис `stale`.
- Бюджет: `--dry-run` з оцінкою токенів, `--limit`, `--jobs`; фейковий агент у тестах.


**Мови:** реалізація мовно-незалежна — однаково для TS/JS, Python, Rust і PHP (і їх суміші в одному репо); тести — щонайменше на двох мовах, з яких одна не PHP.

## Comments

### Рев'ю плану (2026-10-07)

На Magento 7 тис. fn — `explain --missing` коштував ≈ 455 тис. токенів на 147 файлах (рев'ю §3), тобто тут — мільйони. **Рішення:** офлайн-перше: Magento й більшість PHP/Java-подібного коду мають docblock на кожному методі — `tour`/`discover` беруть описи з них (ADR 0004 уже так робить для brief). Модель кличеться лише на рівні **процесу** (десятки запитів, не тисячі), з `--dry-run` і `--limit` обов'язково в тестах.

### Реалізація (2026-10-08)

- **Офлайн-перше.** `discoverFlows` під коментарем `keylang:discover entry=…` пише абзац прози з `doc` тригера (JSDoc / docblock / docstring Python / doc comment Rust, як знімок уже тримає `doc`) і першого речення `doc` кожного кроку одразу під тригером, з походженням `<!-- keylang:discover doc=<id>[,<id>…] -->` (`offlineDescription`, `src/discover.ts`). Детерміновано, без моделі; без жодного doc абзацу немає, тож старі представлення без коментарів не змінились.
- **`flows discover --names [--mode algo|llm|hybrid] [--stale] [--layer l] [--dry-run] [--limit n] [--jobs n]`** (`src/discover-names.ts`, `src/operations/discover-names.ts`): один запит на групу шару тригера, не на потік; відповідь — JSON (назва, 2–4 речення, домен зі списку чи свій, in/out, потоки). Перевірка: невідомі назви потоків відкидаються з рядком у stderr, невідомі ID — `unknown ids: …`. Результат — згенерований `<dir>/flows-discovered/README.md`: домен → процес → потоки з лінками, походження `<!-- keylang:llm model=… date=… closure=… layer=… -->`. README і є сховищем: `parseProcesses` читає його назад.
- **Stale** — як у brief-ів: baseline процесу — sha256 над `snapshotBaseline` кожного кроку його потоків (і назвами потоків). `--stale` питає лише шари stale процесів; без `--stale` — ще й шари з потоками без свіжого процесу. Групи, що відповіли, замінюють свої процеси, решта лишаються.
- **Бюджет:** `--dry-run` (stdout: stale процеси, кількість запитів, оцінка токенів ≈ 4 симв./токен + 300 на групу; нічого не пише, навіть представлення), `--limit` — кількість запитів (з `--names` представлення завжди повне, тож `--limit` і `--layer` звужують запити, не потоки), `--jobs` — як у `explain --missing` (4, для CLI 2).
- **Без моделі:** `hybrid` (типово) — лише представлення з приміткою, `algo` — моделі не кличе, `llm` — код 2, нічого не записано. Помилка групи — код 1, її процеси лишаються.
- **Діаграма:** `{kind:"process", domain}` реалізовано (`DiagramInput.processes`, `processViews`): доріжки за шарами, `start` на кожен потік процесу, `task` на кроки першого рівня; `/api/views` дає `domains` і `processes`; сторінка `/diagrams` показує домени.
- Звичайний `flows discover` README не чіпає й не видаляє (`extraGenerated` його пропускає); `--check` його не порівнює; `check` теку не читає — вердикт від назв не залежить.
- Мови: тести на TS (JSDoc) і Python (docstring) в одному репо; логіка мовно-незалежна (лише `doc` знімка й ID).
- Тести: `tests/discover-names.test.ts` (фейковий `claude` CLI, без мережі): офлайн-описи TS/Python; `--dry-run` нічого не пише й не питає; без моделі hybrid/llm; `--names` пише README з походженням, відкидає невідомі назви, називає невідомі ID; stale після зміни коду кроку і `--stale`; діаграма процесу непорожня.
- TUI-дія «Discover flows» назв не показує (лише офлайн-описи в самому представленні), тож `docs/tui.md` змінено лише в частині API діаграм.
