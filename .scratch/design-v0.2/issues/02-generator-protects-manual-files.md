# 02: Генератор не перезаписує файл без маркера `keylang:generated`

**Етап:** M1.1 · **Джерело:** design §3.2 «Контракт генератора», review RV04

**What to build:** Перед будь-яким записом `keylang map` перевіряє всі цільові файли під `keylang/map/`. Наявний файл без маркера генерації — конфлікт: діагностика зі шляхом і поясненням, код виходу 1, жоден файл не записаний і не видалений. Видаляються лише зайві файли з маркером. Ручні правила, потоки та описи ніколи не зачіпаються.

**Blocked by:** None (can start immediately)

**Status:** resolved

- [ ] Відтворення RV04 (ручний `keylang/map/main.md` без маркера + джерело для шару `main`, `map`): вміст файла незмінний, stdout/stderr називає файл і причину, код виходу 1
- [ ] `map --check` за того ж конфлікту повідомляє його як окремий стан, а не як «stale»
- [ ] жоден інший map-файл не записується, поки є конфлікт (перевірка через mtime/зміст у тимчасовій копії)
- [x] `docs/format.md` розділ про маркер генерації описує контракт «перевірка до запису»

## Answer

`map` і `map --check` повідомляють `manual file without keylang:generated marker` і нічого не пишуть і не видаляють, доки є конфлікт. Конфлікт не називається `stale`.
