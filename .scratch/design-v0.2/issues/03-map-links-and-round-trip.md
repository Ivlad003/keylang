# 03: Посилання карти коректні в GitHub і проходять round-trip власним парсером

**Етап:** M1.1 · **Джерело:** design §3.1 «Прив'язка до коду», §3.2; review RV09, RV10, RV11

**What to build:** Індекс зберігає POSIX-шлях від кореня репозиторію; emitter рахує відносний URL від конкретного map-файлу (`../../src/a.ts#L1`) і кодує спеціальні символи (`%28shop%29`, пробіли, `#`). Парсер декодує URL назад у шлях. Alias залежності не збігається з контекстним ключовим словом (`type`, `fn`, `module`, `event`, `calls`), ID унікальні. Кожен згенерований документ проходить власний парсер без структурних діагностик.

**Blocked by:** None (can start immediately)

## Answer

Посилання відносні до `keylang/map/<шар>.md`. `(` і `)` кодуються додатково до `encodeURIComponent`. Парсер декодує `link.path` і `link.target`. Alias `type` стає `type2`. Карта keylang перегенерована; `map --check` і `parse` проходять.
