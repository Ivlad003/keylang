# 29: TUI, перший зріз: перегляд специфікацій із жолобом доказів

**Етап:** M4 · **Джерело:** design §7.1, §7.4 (Ink 7, мишка через SGR)

**What to build:** `keylang` без аргументів відкриває TUI лише для читання: редактор показує сирий Markdown із підсвіткою (шари, ключові слова, ID), жолоб `✓ / ✗ / ◌` для потрібних критеріїв, розгорнутий рядок з окремими `ID`, `static`, `tests`, `trace`, `planned`, `stale`; спливаюча підказка на hover/`K`; панель навігації праворуч; `Enter` — у вбудований переглядач коду або `$EDITOR`; `F5` — повторний `check`, UI не блокується під час переіндексації. Редагування — у 31.

**Blocked by:** 26

**Status:** resolved

- [x] частковий доказ (`ID ✓`, trace відсутній) не показується як загальне `✓`
- [x] під час переіндексації показано стан «оновлення», старі результати позначені як застарілі
- [x] основні дії перевірені автоматичним тестом рендеру (ink-testing-library або еквівалент) без TTY

## Answer

`keylang` без команди в TTY — `src/tui/` (сесія `app.ts`, чистий рендер `view.ts`, сітка й ANSI-diff `screen.ts`, декодер `input.ts`, жолоб `evidence.ts`, навігація `nav.ts`, читання `markdown.ts`). Ink 7 не взято — бюджет залежностей і type stripping, [ADR 0001](../../../docs/adr/0001-tui-without-ink.md); еквівалент ink-testing-library — сесія з віртуальним терміналом (`tests/vt.ts`, `tests/tui.test.ts`). Позначка `✓` лише коли всі критерії рядка `ok`; розгорнутий рядок показує `ID`/`static`/`tests`/`trace`/`planned`/`stale n/a` окремо. Знімок будує worker; під час аналізу `updating…`, позначки тьмяні, клавіші працюють, результат заміненого покоління відкидається (тести з керованим аналізатором). Hover мишею й `K`, `Enter` у вбудований переглядач або `$EDITOR` (перевірено в pty: `+57 src/cli.ts`, повернення в TUI), `Alt+Enter`, `Ctrl+O`, навігація, `v`, `?`, `:`, `/`. Замір (`bench/results.md`): перший кадр ~105 мс із `dist`, відгук на клавішу ~4 мс під час холодної переіндексації storefront. Дефект, знайдений самоописом: виклики в ініціалізаторах полів класу не були ребрами — тепер належать `constructor` (екстрактор m1.4). Контракт — `docs/tui.md`.
