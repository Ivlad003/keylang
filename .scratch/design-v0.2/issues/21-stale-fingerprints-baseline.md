# 21: Стейлнес прози: fingerprint тіла й транзитивна інвалідація

**Етап:** M2 · **Джерело:** design §4.4, review RV17

**What to build:** Для кожного вузла знімок зберігає fingerprint нормалізованого AST тіла, сигнатури, публічного контракту та релевантних залежностей (консервативний хеш тексту, якщо нормалізація недоступна). Описи вузлів, `when`/`then`/`invariant` у специфікаціях отримують baseline fingerprint, що зберігається під версійним контролем поряд зі специфікацією й оновлюється лише за явного прийняття (`check --stale --accept`?), а не при кожному `map`. `check --stale` показує описи, під якими код змінився, з транзитивною інвалідацією за залежностями, включно з циклами; невідома залежність робить перевірку неповною (позначка). `stale` — попередження для перегляду, не `fail`.

**Рішення для людини:** формат і місце baseline (окремий JSON поряд зі spec, HTML-коментар у рядку, чи `.keylang/baseline.json` у git). Пропозиція: один `keylang/baseline.json` під git, ключ — файл спеки + ID вузла.
