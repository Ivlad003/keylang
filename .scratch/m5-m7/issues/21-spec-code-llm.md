# 21: `code-to-spec`/`spec-to-code` у режимах llm/hybrid

**Етап:** M7 · **Джерело:** design §5.5; батьківський 37

**What to build:** llm-режим: code-to-spec дописує описи, `when`/`then`, інваріанти; spec-to-code — тіло й e2e-сценарій під потік. Усе проходить ті самі обмеження ID, звіряння та MERGE, що draft.

**Blocked by:** 15, 19, 20

**Status:** resolved

- [x] з мок-провайдером: вигаданий ID відхиляється після одного кола
- [x] тіло від LLM аналізується overlay-знімком до пропозиції

## Answer

`code-to-spec --mode llm|hybrid` — через `draftFlowWithModel` (одне коло для вигаданих ID, звіряння, походження); `spec-to-code --mode llm` — тіло від моделі замість заготовки, та сама overlay-перевірка до запису; не та функція → код 2. Тести в `tests/draft.test.ts`. e2e-сценарій доданий 2026-09-28: другий запит до моделі дає файл тесту з назвами тестів потоку; тест без оголошеної назви — код 2, нічого не записано.
