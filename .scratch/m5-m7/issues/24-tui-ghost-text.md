# 24: TUI: ghost-текст з метриками

**Етап:** M7 · **Джерело:** design §7.3; батьківський 38

**What to build:** Один рядок сірим після паузи (параметр, дефолт 400 мс) і дешевого сигналу; `Tab` приймає, `Alt+]` варіанти, `Esc` прибирає; лише ID знімка або оголошені `planned`. Прийняття/відхилення й час пишуться в `.keylang/stats.json` поряд із метриками детермінованого автодоповнення.

**Blocked by:** 23

**Status:** resolved

- [x] без сигналу ghost не з'являється
- [x] ghost ніколи не містить невідомого ID (мок пропонує вигаданий → відкинуто)
- [x] метрики записано локально

## Answer

`src/ghost.ts` (`ghostSignal`, `ghostSuggestions` з перевіркою ID через парсер) + TUI: таймер паузи (`ghost.delay`, у `idle()`), сірий рядок із лічильником варіантів, `Alt+]`/`Tab`/`Esc`; метрики `suggestions.ghost` і `suggestions.completion` (proposed/accepted/rejected/ms). Тест: без сигналу запиту немає; вигаданий ID відкинуто; Tab ставить рядок; Esc — rejected. Порівняння корисності ghost проти автодоповнення — дані збираються, самого виміру з людьми ще немає.
