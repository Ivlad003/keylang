# 08: Wiring: виконуваний прототип життєвого циклу й ADR

**Етап:** M6 · **Джерело:** design §6, §10.10; батьківський 34

**What to build:** Виконуваний приклад контракту: фабрики, async init/dispose, області життя (singleton/scoped), порядок ініціалізації за топологією й поведінка на циклах (заборона чи лінивий проксі з визначеною помилкою доступу до неініціалізованого). Рішення записано як ADR `docs/adr/0003-…` зі статусом `proposed`; прийняття — за людиною.

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] прототип запускається `node` і демонструє init у топологічному порядку, dispose у зворотному, визначену помилку на циклі
- [x] ADR описує варіанти, обране рішення й наслідки для codegen

## Answer

Прототип `examples/wiring-lifecycle/` (`plan.ts` — топологічний порядок або цикл; `demo.ts` — рукописна форма згенерованого `wire()`): init у топологічному порядку, dispose у зворотному, rollback на помилці init, цикл — `{cycle: [a, b, a]}`. [ADR 0003](../../../docs/adr/0003-wiring-lifecycle.md) — статус **запропоновано**: пряма згенерована функція без контейнера, цикли заборонено, одна область життя в v1. **Людині:** прийняти чи змінити ADR 0003; 09–10 реалізовано за цим проєктом.
