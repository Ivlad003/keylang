# 18: MCP: `explain` і `apply_diff` як пропозиція

**Етап:** M7 · **Джерело:** design §7.3; батьківський 36

**What to build:** `explain` віддає кешоване пояснення або algo-зведення; `apply_diff` лише записує пропозицію в `.keylang/proposals/` і повертає diff зі статусом `pending` — файли специфікацій не змінюються до MERGE людиною.

**Blocked by:** 13, 17

**Status:** resolved

- [x] `apply_diff` не змінює цільовий файл, пропозиція видна в TUI через `m`
- [x] ціль поза `keylang/` відхиляється з причиною

## Answer

`explain` (збережене пояснення зі `stale` або офлайн-зведення, модель не викликається) і `apply_diff` (лише пропозиція `.keylang/proposals/<path>`, статус `pending`, diff; правила цілі — спільні з TUI через `src/proposals.ts`). Тести: специфікація не змінюється, код/карта відхиляються з причиною.
