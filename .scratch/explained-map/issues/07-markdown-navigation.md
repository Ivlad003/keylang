# 07: Навігація в Markdown: якорі, лінки, зміст

**Джерело:** рішення користувача 2026-09-28 (п. 3 spec, «Markdown у GitHub/редакторі»)

**What to build:** У карті з поясненнями кожен вузол має якір: `<a id="<ID>"></a>` на початку його рядка опису або в окремому рядку опису, якщо пояснення немає. `calls` і цілі залежностей записуються лінками `[id](<layer>.md#<id>)` на якір вузла у файлі його шару (06). Зовнішні модулі теж отримують якір у `external.md`. `README.md` — стартова сторінка: шари з поясненнями й лінками на файли, лічильники за походженням (код / llm / llm stale / без пояснення). Він також має плоский алфавітний покажчик модулів і класів з лінками на якорі, щоб шукати через `Ctrl+F`. Файл шару починається зі змісту своїх модулів. Усе детерміноване, шляхи — відносні POSIX.
