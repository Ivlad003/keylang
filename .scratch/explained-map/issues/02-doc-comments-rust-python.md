# 02: Коментарі документації Rust і Python

**Джерело:** spec «Припущення»; тікет 01

**What to build:** Той самий контракт `doc`, що в 01, для інших frontend-ів. **Rust:** `///` і `/** */` над item (атрибути між ними дозволені), `//!` і `/*! */` — документація модуля, зокрема `mod.rs`/`lib.rs` для модуля-теки. **Python:** docstring — перший рядковий вираз тіла модуля, `def`, `class`. Для модуля-теки береться `__init__.py`. Перетворення на brief-текст спільне з 01: це одна чиста функція, а не копія для кожної мови.

**Blocked by:** 01

**Status:** resolved

- [x] фікстури `rust-shop` і `py-shop` отримують документацію на кожному рівні; `index.json` містить `doc`
- [x] `#[doc = "…"]` і docstring у f-рядку — `doc: null` (не вигадуємо текст)
- [x] канонічні карти фікстур не змінюються
- [x] format.md §11 «Мови» згадує джерела документації для кожної мови
