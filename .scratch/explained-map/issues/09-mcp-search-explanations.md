# 09: MCP `search` за поясненнями

**Джерело:** рішення користувача 2026-09-28 (п. 3 spec, «MCP search для агентів»); grammar.md §9 «keylang mcp»

**What to build:** Інструмент `search` шукає за ID, як зараз, а також за текстом пояснення (підрядок без урахування регістру). Спершу йдуть збіги за ID, потім за текстом, порядок стабільний. Кожен результат має `explanation: { text, origin: "doc" | "llm", stale } | null`. Інструмент `node` повертає те саме поле. Опис інструмента в MCP каже, що пошук іде й за поясненнями. Пояснення читаються через спільний lookup із 03/04. Пошук за поясненням працює й без увімкненої `explain.map`: пояснення є властивістю вузла, а не файла карти.
