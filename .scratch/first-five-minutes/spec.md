# П'ять хвилин до користі: keylang як паркан для агентів і CI

**Джерело:** [рев'ю 2026-11-19](../../docs/review-2026-11-19.md), §3 і §7 «Транш 1».

## Мета

Людина, що вперше бачить keylang, за п'ять хвилин доходить до першої корисної відповіді: `npx keylang init .` → `npx keylang check` → навмисний заборонений імпорт → K102 із рядком, що каже, як це виправити → той самий `check` у CI. Шлях не вимагає ні читати курс, ні знати про студію, діаграми, system design чи wiring.

## Рішення людини (2026-11-19)

- Головна роль продукту — **паркан для агентів і CI** (робота B у рев'ю, §1). «Розібратися в чужому репо» (`tour`, `entries`, `coverage`) — безкоштовний вхід у неї; spec-first розробка — просунутий трек курсу.
- Периферію **позначити experimental**: код лишається, але зникає з короткої довідки та README. Нових поверхонь не додавати, доки сторонні люди не пройдуть основний цикл.

## Критерій готовності фічі

- `keylang --help` вміщується на один екран і починається з `init` і `check`.
- `init` закінчується рядком із наступною командою.
- K102 у людському виводі `check` містить виправлення.
- `examples/fence` запускається як є і показує K102 однією правкою.
- README відкривається трьома командами паркана.
- CI цього репозиторію зелений; рецепт CI для користувачів задокументовано.

Перевірка всієї фічі — ручний прохід на свіжому TS-репозиторії з тимчасової теки: `init`, `check`, доданий заборонений імпорт, `check` (K102, код 1), повернений імпорт, `check` (код 0).

## Несумісні зміни

- **01:** вивід `keylang --help` коротшає; повний текст — `keylang help --all`. Без команди й без TTY stderr містить коротку довідку замість повної (код 2 без змін). Скрипти, що парсять `--help`, мають перейти на `help --all`.
- **03:** текст `message` у K101, K102, K104, K105 отримує хвіст із виправленням — у людському виводі й у полі `message` JSON, SARIF і `github`. Поля й коди виходу не змінюються.
- **08:** якщо людина вибере варіант (а), `init` без `--agents` перестане писати `AGENTS.md` і файли харнесів.
