## Кроки

1. Зіставити кожен рядок матриці з action ID/alias/формою. Додати відсутні aliases й перехресні переходи unavailable → config/doctor/інтеграції.
2. Help і footer будуються з актуальних bindings/режиму. `?` у edit не рекламується як help-key, якщо це звичайний ввід; допомога досяжна з Ctrl+P.
3. За cols < 100 показувати одну допоміжну панель замість стиснення всіх. Форми, help, results і proposals прокручуються; Run/Back/Cancel мають досяжний клавіатурний шлях.
4. Resize з відкритою формою/результатом не губить поля, вибір, cursor чи active job. Esc повертає первісне місце.
5. Довгі шляхи/Unicode обрізати за клітинками з можливістю прочитати повний текст у деталях; не різати escape-послідовності або графеми.
6. Перевірити Ctrl+G, ghost/voice, F4, e, u, пошук і code navigation як дії каталогу без зміни їхнього контракту. Документацію поточної поведінки доповнити лише реально готовими можливостями.

## Перевірки

- На 80×24 пройти пошук → багатопольна форма → помилка поля → Run → F6 → Esc лише клавішами.
- На 60×18 прокрутити довгий звіт/довідку й дістатися основної дії; resize 120↔60 зберігає дані.
- Для кожного CLI-alias прикладної матриці є дія; unavailable має причину, протокольні сервери не маскуються як прикладні jobs.
- Ctrl+G над dirty-абзацом лишає прозу й записує лише буфер до Ctrl+S; старі швидкі дії працюють.
