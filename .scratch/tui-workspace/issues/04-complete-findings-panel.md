## З чого почати

Знайти `checkResults`, `sameFinding`, `lineEvidence`, `counts`, `CodeView`, переходи definition/code та формат JSON check. Не робити звіт із позначок жолоба.

## Кроки й рішення

1. У F6 закріпити пункт поточного analysis, окремо від завершених дискових операцій.
2. Будувати список через чинне перетворення результатів check: ті самі критерії, коди, порядок, deduplication, file/line/col та provenance.
3. Рядок показує verdict, code/criterion, file:line:col і повідомлення. Деталі — докази, snapshotId, причина unverified.
4. Enter відкриває spec-позицію або read-only код; не вимагати, щоб файл був серед Markdown-буферів. Ctrl+O/Esc повертає до списку без втрати вибору.
5. Додати фільтри verdict із кількостями прихованих результатів. Лічильники звіту рахують findings, не рядки. Жолоб лишається агрегованим.
6. Показати overlay/outdated/error й не підміняти цей список майбутнім strict/changed-звітом операції.

## Поведінкові перевірки

- Заборонений import дає K102 на коді: знайти його в F6, Enter показує потрібний рядок.
- Дві різні знахідки на одному рядку не зливаються в одну; diagnostic/verdict дубль не показується двічі.
- На збережених входах список порівнюється з CLI JSON по публічних полях; службові абсолютні шляхи нормалізувати однаково.
- З фільтром видимі лише потрібні вердикти, повні totals і початковий звіт не змінені.

## Result

Реалізовано A29, A30 і parity з A06 для F6 → «Current analysis».

- **`src/tui/findings.ts`** (новий): `findingsOf` викликає спільний із CLI/MCP `checkResults`, кешований на об'єкт аналізу (`WeakMap`). Є `VERDICTS`, фільтр, `FILTER_KEYS` (`f/u/w/o`), лічильники знахідок, рядок списку `findingRow`, метадані `findingDetailText`, `sameResult`.
- **`src/tui/app.ts`**: закріплений пункт аналізу над записами doctor. `Enter` відкриває знахідку одразу, `Tab` перемикає стрілки між пунктами й знахідками. Spec-позиція: колонку з code points переведено в кластери, файл не мусить бути відкритим буфером. Код відкривається в read-only переглядачі; `showCode` спільний із `jump`, CRLF тепер розбирається коректно. `Esc`/`Ctrl+O` (у коді ще `q`) повертають до списку з тим самим вибором і відновлюють місце й режим, звідки відкрито знахідку; `Esc` у редагуванні спершу виходить із нього. `F6` над ціллю закриває панель і лишає ціль. У MERGE знахідка не відкривається, щоб не загубити рішення. Після повторного аналізу вибір лишається на тій самій знахідці. Коліщатко рухає вибір.
