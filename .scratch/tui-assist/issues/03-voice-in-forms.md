# 03: Голос у підказках і формах TUI

**Status:** ready-for-agent

**Type:** code

**Blocked by:** None (can start immediately)

**Verify:** `node --test tests/tui-voice-forms.test.ts` · `npm run typecheck` · `npm test` · `node bin/keylang.js map --check` · `node bin/keylang.js check --strict`

**Джерело:** spec §3, §4.4, П4; [ADR 0019](../../../docs/adr/0019-tui-assistant-without-harness.md) (інваріант голосу); design §7.3 «Голосовий ввід»

**What to build:** Зараз `Ctrl+R` працює лише в буфері редактора в режимі редагування (`Assist.voice`, `src/tui/assist.ts`). У перегляді він тільки зупиняє запис, а в підказках і формах його ігнорує `promptKey` (`src/tui/prompt-keys.ts`). Тікет додає голос у відкриту підказку: палітру, пошук, пошук вузла, форми операцій.

- **Куди йде текст.** Розпізнаний текст потрапляє у вибраний рядок за видом поля (таблиця spec §4.4): запит, вибір зі списку, вільний текст. Вид голосу задає саме поле (`TextField`). Поле без виду — шлях, число, вибір — голос не пише.
- **Один конвеєр.** Рушій, мікрофон, вікна й глосарій лишаються спільними з редактором. Ціль запису — буфер або поле підказки, і текст потрапляє лише туди, де запис почався: та сама підказка й той самий рядок.
