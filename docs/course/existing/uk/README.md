# Додавання до кодової бази

[Курс](../../uk/README.md) · [English](../README.md) · **Українською**

![Ключ до розробки і розуміння проектів](../../images/banner.png)

Репозиторій уже є. Треба додати фічу або підключити бібліотеку так, щоб новий код не ліз куди не треба.

Ви пишете специфікацію фічі. Агент генерує з неї код. Функції ви не пишете. keylang агента не запускає. Він перевіряє, що новий код лишається в правилах.

Якщо `check` новий, спершу [урок 2](../../uk/02-install-and-check.md). Якщо слова «шар» і `deny` нові, [підготовчий курс](../../pre/uk/README.md) — це крамниця, без команд.

| Частина | Ви зможете |
|---|---|
| [1. Перша година](01-the-first-hour.md) | Навести keylang на репозиторій і лишити два-три правила |
| [2. Нова фіча](02-a-feature.md) | Записати те, чого в коді ще немає, і знати, коли воно готове |
| [3. Інтеграція](03-an-integration.md) | Додати пакет так, щоб ядро його не імпортувало |

Приклади продовжують крамницю: оформлення покупки вже є. Ви додаєте повернення, потім оплату карткою.
