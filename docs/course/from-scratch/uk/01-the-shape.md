# 1. Форма

[Проєкт з нуля](README.md) · [English](../01-the-shape.md) · **Українською**

Дайте програмі чотири роботи. Ті самі чотири, що в крамниці.

- **presentation** — край, якого торкається людина або інша програма. Оновлення бота, HTTP-шлях, контролер.
- **application** — одне завдання. Зберегти нотатку. Створити задачу. Оформити замовлення.
- **domain** — правила, які лишаються правдою, навіть якщо мережу вимкнути. У нотатки є текст. У задачі є назва.
- **infrastructure** — бібліотека, база, API бота. Воно стоїть поруч із трьома іншими, не під domain.

Domain не імпортує infrastructure. Край теж не імпортує. Завдання посередині може.

```markdown
# rules

- layers domain < application < presentation
  - infrastructure
- deny domain infrastructure
- deny domain external
- deny presentation infrastructure
```

Створіть застосунок його власним інструментом. Потім:

```sh
npx keylang init .
```

Замініть вгадані шари в `keylang.json` на шляхи з наступної частини. `keylang check` на фічі, яка ще лише побажання, дає код 1. Це перший день, не зламаний інструмент.

`keylang feature <slug>` готовий, коли кожен рядок `planned` у тому файлі збігається з кодом, кожен крок має статичний шлях виклику і жодне правило не падає. Тести і trace друкуються поруч із цією відповіддю. Вони її не вирішують. Код виходу 0 друкує `done` у stderr.
