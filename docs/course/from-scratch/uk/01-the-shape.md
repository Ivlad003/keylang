# 1. Форма

[Проєкт з нуля](README.md) · [English](../01-the-shape.md) · **Українською**

Дайте програмі чотири роботи — ті самі чотири, що й у крамниці.

- **presentation** — край, якого торкається людина або інша програма: оновлення бота, HTTP-маршрут, контролер.
- **application** — одне завдання, наприклад зберегти нотатку, створити задачу чи оформити замовлення.
- **domain** — правила, які лишаються правдою навіть тоді, коли мережу вимкнено: у нотатки є текст, у задачі є назва.
- **infrastructure** — бібліотека, база, API бота. Цей шар стоїть поруч з іншими трьома, а не під domain.

Domain не імпортує infrastructure, і край теж не імпортує. Це може робити лише завдання посередині.

```markdown
# rules

- layers domain < application < presentation
  - infrastructure
- deny domain infrastructure
- deny domain external
- deny presentation infrastructure
```

Цей файл пишете ви самі. Наступні частини називають функції, але ці функції пише агент, а не ви.

Спершу створіть порожній застосунок його власним інструментом. Потім запустіть:

```sh
npx keylang init .
```

Замініть вгадані шари в `keylang.json` на шляхи з наступної частини. Поки фіча — лише побажання, `keylang check` на ній завершується з кодом 1. Для першого дня це нормально і не означає, що інструмент зламаний.

`keylang feature <slug>` повідомляє, що фіча готова, коли кожен рядок `planned` у тому файлі збігається з кодом, кожен крок має статичний шлях виклику і жодне правило не падає. Тести і trace друкуються поруч із цією відповіддю, але не впливають на неї. З кодом виходу 0 команда друкує `done` у stderr.

Якщо новий проєкт переносить процес, який уже є в старому, першу фічу можна взяти звідти: `keylang flow export <потік> --out flow.bundle.md` у старому репозиторії, `keylang flow import flow.bundle.md` у новому. Без `--layer-map` кожен старий шар іде в шар із тим самим ім'ям, інакше — у ваш перший шар із приміткою; `--mode hybrid` просить модель зіставити шари за назвами й описами, а відповідь, що називає шар, якого у вас немає, повертається до цього правила. Результат — пропозиція фічі з рядками `planned` і старими сигнатурами, той самий початок, що й написаний вручну.
