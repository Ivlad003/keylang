# Проєкт з нуля

[Курс](../../uk/README.md) · [English](../README.md) · **Українською**

![Ключ до розробки і розуміння проєктів](../../images/banner.png)

keylang не створює застосунок за вас. У бота своя бібліотека, у CRUD свій фреймворк, а в Nest є `nest new`, тож порожній проєкт ви спершу створюєте саме ними. Потім пишете короткий текст про те, хто кого може знати. Код із цього тексту генерує агент, тож функції ви не пишете, а keylang агента не запускає. Що робить keylang — це валить перевірку, коли код розходиться з текстом.

Нарисів три, і в кожному ті самі три файли: `keylang.json`, `keylang/rules.md` і один файл у `keylang/features/`. Агент заповнює код, доки `keylang feature <slug>` не скаже done.

Якщо слова для вас нові, спершу пройдіть [підготовчий курс](../../pre/uk/README.md). Команди на цих сторінках ті самі, що й в [уроці 2](../../uk/02-install-and-check.md).

| Частина | Проєкт |
|---|---|
| [1. Форма](01-the-shape.md) | Чотири роботи, ще до будь-якого з трьох застосунків |
| [2. Telegram-бот](02-telegram-bot.md) | `/start` зберігає нотатку, а бібліотека бота лишається на краю |
| [3. Python CRUD](03-python-crud.md) | Створити задачу; HTTP-маршрут не говорить з базою |

Коли файли вже є, копіюйте id з `keylang map`. Id на цих сторінках — це те, що ви отримаєте, якщо ваші теки збігаються з наведеними тут glob-ами.
