# Проєкт з нуля

[Курс](../../uk/README.md) · [English](../README.md) · **Українською**

![Ключ до розробки і розуміння проектів](../../images/banner.png)

keylang не створює застосунок. У бота своя бібліотека. У CRUD свій фреймворк. У Nest є `nest new`. Спершу створюєте той проєкт. Потім keylang — це короткий текст, хто кого може знати, і перевірка, яка падає, коли код розходиться з текстом.

Три нариси. Щоразу ті самі чотири файли: `keylang.json`, `keylang/rules.md` і один файл у `keylang/features/`. Код росте, доки `keylang feature <slug>` не скаже done.

Якщо слова нові, спершу [підготовчий курс](../../pre/uk/README.md). Команди на цих сторінках ті самі, що в [уроці 2](../../uk/02-install-and-check.md).

| Частина | Проєкт |
|---|---|
| [1. Форма](01-the-shape.md) | Чотири роботи, ще до трьох застосунків |
| [2. Telegram-бот](02-telegram-bot.md) | `/start` зберігає нотатку. Бібліотека бота лишається на краю |
| [3. Python CRUD](03-python-crud.md) | Створити задачу. HTTP-шлях не говорить з базою |
| [4. Застосунок NestJS](04-nestjs.md) | Той самий розріз у TypeScript, з декораторами Nest |

Копіюйте id з `keylang map`, коли файли вже є. Id нижче — це те, що виходить, коли теки збігаються з glob-ами на цій сторінці.
