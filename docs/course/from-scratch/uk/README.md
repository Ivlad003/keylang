# Проєкт з нуля

[Курс](../../uk/README.md) · [English](../README.md) · **Українською**

![Ключ до розробки і розуміння проєктів](../../images/banner.png)

keylang не створює застосунок за вас. У бота своя бібліотека, у CRUD свій фреймворк, а в Nest є `nest new`, тож порожній проєкт ви спершу створюєте ними. Потім пишете короткий текст про те, хто про кого може знати. Код із цього тексту генерує агент, тож функції пишете не ви, а keylang агента не запускає. Робота keylang — провалити перевірку, коли код розходиться з текстом.

Нарисів три, і кожен спирається на ті самі три файли: `keylang.json`, `keylang/rules.md` і один файл у `keylang/features/`. Агент пише код, доки `keylang feature <slug>` не скаже done. У частині 5 ви натомість малюєте шари й процес, а ці три файли за малюнком пише `keylang web --new`.

Якщо терміни вам незнайомі, спершу пройдіть [підготовчий курс](../../pre/uk/README.md). Команди на цих сторінках ті самі, що й в [уроці 2](../../uk/02-install-and-check.md).
