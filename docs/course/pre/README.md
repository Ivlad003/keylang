# Pre-course

[Course](../README.md) · **English** · [Українською](uk/README.md)

Read this before the [course](../README.md) if an agent will write the code for you and you have never drawn an architecture yourself. Your part is the spec; the agent writes the functions. There are no commands to run here, only ideas, and every idea is shown on the same small shop from [`examples/shop`](../../../examples/shop).

You do not need to learn patterns or a catalogue of architectural styles first, because keylang checks just two things: which part of the program is allowed to know about which other part, and whether a scenario you have named still matches the code.

| Part | What happens |
|---|---|
| [1. A shop](01-the-shop.md) | One program grows, and four jobs show up before any term does |
| [2. The words](02-the-words.md) | Each word explained on that same shop |
| [3. The principles](03-principles.md) | The decisions you are actually making |
| [4. What to read](04-reading.md) | A short reading path, with the free sources |

Once you finish part 3, you are ready for [lesson 1](../01-what-it-is.md). Part 4 is optional reading, so you can start the course without it.
