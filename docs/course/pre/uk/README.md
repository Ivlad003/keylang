# Підготовчий курс

[Курс](../../README.md) · [English](../README.md) · **Українською**

Читайте це перед [курсом](../../uk/README.md), якщо код писатиме агент, а архітектуру ви ще не малювали. Специфікацію пишете ви. Функції — ні. Команд тут немає. Ідеї — на крамниці з [`examples/shop`](../../../../examples/shop).

Патерни і каталог стилів не потрібні. keylang перевіряє дві речі: яка частина програми може знати іншу, і чи сценарій, який ви назвали, досі збігається з кодом.

| Частина | Що відбувається |
|---|---|
| [1. Крамниця](01-the-shop.md) | Програма росте. Чотири роботи з'являються раніше за терміни |
| [2. Слова](02-the-words.md) | Кожне слово — на тій самій крамниці |
| [3. Принципи](03-principles.md) | Рішення, які ви насправді ухвалюєте |
| [4. Що читати](04-reading.md) | Короткий шлях і безкоштовні джерела |

Після частини 3 можна відкрити [урок 1](../../uk/01-what-it-is.md). Частина 4 курс не блокує.
