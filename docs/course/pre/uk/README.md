# Підготовчий курс

[Курс](../../README.md) · [English](../README.md) · **Українською**

Цю частину варто прочитати перед [курсом](../../uk/README.md), якщо код за вас писатиме агент, а архітектуру ви самі ще ніколи не малювали. Ви пишете специфікацію, агент пише функції. Запускати тут нічого не треба: є лише ідеї, і кожну показано на одній невеликій крамниці з [`examples/shop`](../../../../examples/shop).

Заздалегідь вивчати патерни чи каталог архітектурних стилів не потрібно. keylang перевіряє лише дві речі: яка частина програми може знати про яку іншу і чи сценарій, який ви назвали, досі відповідає коду.

| Частина | Що відбувається |
|---|---|
| [1. Крамниця](01-the-shop.md) | Програма росте, і чотири роботи з'являються раніше за будь-які терміни |
| [2. Слова](02-the-words.md) | Кожне слово пояснено на тій самій крамниці |
| [3. Принципи](03-principles.md) | Рішення, які ви насправді ухвалюєте |
| [4. Що читати](04-reading.md) | Короткий шлях читання і безкоштовні джерела |

Коли закінчите частину 3, можна переходити до [уроку 1](../../uk/01-what-it-is.md). Частина 4 — додаткове читання, тож курс можна почати й без неї.
