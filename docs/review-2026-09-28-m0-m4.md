# keylang — код-рев'ю M0–M4

Дата: 2026-09-28. Охоплення: увесь код етапів M0–M4 після виправлень з [рев'ю M4](review-2026-09-28.md). Зон чотири, у кожній окремий рецензент: ядро мови й правила, LSP/CLI/адаптери/пакування, TUI і web (повторно, після виправлень), аналізатор (extract, graph, flows). Кожну знахідку відтворено на тимчасовому репозиторії або скриптом. Нижче знахідки й те, що з ними зроблено.

**P1** — хибний успіх або хибна відмова основної перевірки, втрата даних, падіння. **P2** — хибний результат окремого правила чи представлення. **P3** — якість.

## Що лишається відкритим

- Тікети 21 (стейлнес прози, `stale n/a`) і 28, етапи M5–M7 (зокрема `e` і статуси `=`/`+?`/`!` чернетки) — дорожня карта, не дефекти.
- Підсвітка коду в TUI лексична, не з `highlights.scm` (компроміс ADR 0001).
- static `fail` на реальному коді рідкісний за побудовою: функцію, прочитану як значення, keylang розпізнає за назвою; точніше — лише з аналізом потоку значень.
- Ребро `injected` не розрізняє контекст виклику (діє для будь-якого виклику функції-хука).
