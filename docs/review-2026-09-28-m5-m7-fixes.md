# keylang — що зроблено зі знахідками рев'ю M5–M7

Дата: 2026-09-28. Три рев'ю коміту `7cce8c2`: [повне](review-2026-09-28-full.md) (далі FULL), [сесійне](review-2026-09-28-session.md) (SESSION) і зовнішнє рев'ю Grok (GROK, 10 знахідок, файл поза репозиторієм; зміст кожної коротко наведено нижче). Виправлення зроблено по семи зонах, кожна — окремим комітом, плюс коміти на стиках зон; кожну знахідку спершу відтворено, і майже для кожної є поведінковий тест, який падає на `7cce8c2`.

**Перевірки після всіх змін:** `npm run typecheck` — 0; `npm test` — 337 тестів, 336 pass, 1 skipped (whisper без моделі), 0 fail — і на Node 24.20, і на Node 22.18 (мінімум з `engines`); tarball на обох версіях запускає `map` на Rust- і Python-фікстурах; `keylang map --check` — 0; `keylang check --strict` — 0 fail, 0 unverified, 65 ok.

**Стан:** ✔ виправлено · ≈ за задумом (з поясненням у специфікації) · ✗ не відтворено · ◐ частково.

## Несумісні зміни контракту

- Шари `external`, `unassigned` і ключові слова верху карти (`layer`, `layers`, `allow`, `deny`, `entry`, `module`, `no-cycles`) зарезервовано: `keylang.json` із таким шаром — код 2.
- `allow`/`deny` з ID fn, типу, події чи аліаса — K005, а не мовчазний `ok`. Усі рядки `layers` — один частковий порядок; суперечність — K005.
- Специфічність правил рахується в сегментах ID, а не в символах.
- `layers` і `entry` мають власні вердикти `ok`/`unverified`; K103 — лише попередження, не `fail`.
- Знімок — схема **6** (маркер класу, `static`/`name` у fn, ідентичність експорту), екстрактор `m1.8`; колонки коду — у кодових точках.
- JSON/SARIF: кожен результат має `specHash` і `provenance`; `unverified` у SARIF/GitHub — `ruleId: unverified`; SARIF оголошує `columnKind`.
- Без `check.tests` рядків `tests` немає; неповний trace-запуск нічого не підтверджує; `dropped`/`open`/`complete` неправильного типу — код 2.
- LSP: кадр без `Content-Length` — код 2. TUI: сигнал завершує з кодом 0 (було 128 + n), збій — 2.
- `spec-to-code --apply`, `wire --out` і всі записи CLI та TUI йдуть одним протоколом (`src/safe-write.ts`): лише відносний шлях у репозиторії, посилання назовні — відмова, запис атомарний.

## Відкрите

- **`sortIds` і ICU** (підозра FULL TS): офіційні збірки Node ≥ 22 мають full-icu; заміна `localeCompare` переставила б усі карти. Не змінено — рішення за власником.
- **Знайдено агентами, поза рев'ю:** атрибут класу Python (`run = helper`) і типовий метод Rust `trait` не стають членами, тож крок на них дає K001; нелітеральний `__all__` трактується як відсутній; `from x import *` у звичайному модулі лишає виклики `dynamic-call`; резолвер Rust бачить `mod x;` незбереженого буфера лише з диска.
- **Не перевірялось:** Windows-шляхи, справжній whisper.cpp і мікрофон (лише підставні модулі), зникнення мікрофона браузера після `mic off` (без браузера — лише код).
- `MAX_DEPTH = 1000` у TS: глибше вкладений файл стає `opaque` — правила над ним `unverified`, хибного `ok` немає.
